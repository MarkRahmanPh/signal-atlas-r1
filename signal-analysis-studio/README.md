# Signal Analysis Studio

Experimental client-side viewer for the ODOT Signal Analysis Tool workbook. Upload .xlsm or .xlsx to inspect seven worksheets. Files are parsed in-browser, not stored or uploaded; VBA is not executed. Current prototype is a workbook explorer only, not a validated port of signal measures. For full source and implementation roadmap see the downloadable project package supplied in ChatGPT.

Do not commit original cabinet configurations or traffic logs to a public repository.
